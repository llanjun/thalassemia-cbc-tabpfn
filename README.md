# CBC-Based Thalassemia Screening

**Manuscript title:** *Interpretable TabPFN for thalassemia carrier prediction from complete blood counts: threshold trade-offs and phenotype-specific errors*  
**Authors:** Xueyan Wang, Lanjun Luo

Open-source code for two analyses based on complete blood count (CBC) data:

- Task 1: carrier versus non-carrier classification.
- Task 2: alpha versus beta classification among eligible carriers.

The public run uses the synthetic dataset in `data/sim_data/`.

## Run

Python 3.11 is recommended. Use the `thal_mini` environment or another clean environment:

```bash
conda create -n thal_mini python=3.11 -y
conda activate thal_mini
pip install -r code/requirements.txt
```

Run from the repository root:

```bash
python code/main_prediction.py
python code/post_hoc_interpretation.py
```

The second script reads the models and prediction files created by the first script.

TabPFN downloads its pretrained weights on the first run. The optional external CatBoost weights are not included in this public repository; without them, the corresponding zero-shot comparator is skipped.

## Scripts

`code/main_prediction.py` fits the models, calculates predictions and locked thresholds, saves the two primary TabPFN models, and generates Figures 2–8.

`code/post_hoc_interpretation.py` reads the prediction files, generates SHAP, ALE, PCA, error, subgroup, and calibration analyses, and generates Figures 9–13 plus supplementary calibration figures.

Figure 1 is not generated by these scripts.

## Data and output

- `data/sim_data/`: synthetic input data for public runs.
- `data/`: private clinical data and external model weights; not included.
- `output/`: generated models, predictions, thresholds, explanation files, and figures. This directory is created when the scripts run.
- `code/requirements.txt`: pinned Python dependencies.

To use another dataset, update `DATA_FILE` in both scripts and provide the fields described in [`data/sim_data/README.md`](data/sim_data/README.md). Task 2 uses only records labelled `alpha` or `beta`.
